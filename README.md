# Housing_price_prediction.ml
**California housing price prediction with machine learning**

The project uses the California Housing dataset from Scikit-learn to predict median house prices using a machine-learning neural network

## Features

| Features | Meaning |
|----------|---------|
| MedInc | Median income of households in the block group |
| HouseAge | Median age of houses |
| AveRooms | Average number of rooms per household |
| AveBedrms | Average number of bedrooms per household |
| Population | Population of the block group |
| AveOccup | Average number of household members |
| Latitude | Geographic latitude |
| Longitude	| Geographic longitude |

## installation

1. Clone the repository :

```bash
git clone https://github.com/34TW/hosuing_prediction_ml.git
```

2. Enter the directory :

```bash
cd hosuing_prediction_ml
```

3. Install the dependencies :

```bash
pip install -r requirements.txt
```

4. Run the application :

```bash
python main.py
```

## Requirements

- matplotlib

## Folder usage

- **README.md**: its main documentation file of a project

- **requirements.txt**: specifies the packages and tools for the project

- **data**: store raw datasets and preprocessed data

- **notebooks**: for experimentation, model hyperparameter tuning and trying every option for the best model performance  

- ** src **: source of the main Python code

- **models** : save the model
